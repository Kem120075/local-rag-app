📚 Local Multi-PDF RAG Chatbot

A fully local Retrieval-Augmented Generation (RAG) system that lets you chat with multiple PDF documents at once — with page-level source citations for every answer. No cloud APIs, no data leaving your machine.

Built with **Streamlit**, **LangChain**, **ChromaDB**, and **Ollama**.

---

✨ Features

- 📄 Multi-PDF upload — index and query several documents at once
- 💬 Conversational chat interface — ask natural-language questions about your documents
- 📌 Source citations — every answer shows exactly which file and page number it came from
- 🔒 100% local & private — runs entirely on your machine using Ollama; no data sent to external APIs
- ⚡ Fast local embeddings — powered by `nomic-embed-text` via Ollama
- 🧠 Lightweight local LLM — answers generated by `llama3.2:1b`, no GPU required

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| UI | [Streamlit](https://streamlit.io/) |
| Orchestration | [LangChain](https://www.langchain.com/) |
| Vector Store | [ChromaDB](https://www.trychroma.com/) |
| LLM & Embeddings | [Ollama](https://ollama.com/) (`llama3.2:1b`, `nomic-embed-text`) |
| PDF Parsing | [pypdf](https://pypi.org/project/pypdf/) |

---

🧩 How It Works

1. Upload one or more PDFs through the sidebar.
2. Each PDF is loaded, split into overlapping text chunks, and tagged with its source file name and page number.
3. Chunks are embedded locally using `nomic-embed-text` and stored in an in-memory ChromaDB vector store.
4. When you ask a question, the top relevant chunks are retrieved and passed to `llama3.2:1b`, which generates an answer **grounded only in your documents**.
5. Every response includes an expandable **Source Citations** panel showing the exact file(s) and page number(s) used.

🚀 Getting Started

1. Clone the repository
```bash
git clone https://github.com/Kem120075/local-rag-app.git
cd local-rag-app
```

2. Create and activate a virtual environment
```bash
python -m venv venv
```

Windows (PowerShell):
```powershell
.\venv\Scripts\Activate.ps1
```

macOS/Linux:
```bash
source venv/bin/activate
```

3. Pull the required Ollama models
```bash
ollama pull llama3.2:1b
ollama pull nomic-embed-text
```

4. Install Python dependencies
```bash
pip install streamlit langchain-community langchain-text-splitters langchain-chroma langchain-ollama pypdf
```

5. Run the app
```bash
streamlit run main.py
```

The app will open automatically at **http://localhost:8501**.

> Full setup walkthrough, including troubleshooting for Windows execution-policy errors, is available in [`RAG_SETUP.md`](./RAG_SETUP.md).

---

 💡 Usage

1. Open the app in your browser.
2. Use the **Document Setup** sidebar to upload one or more PDF files.
3. Wait for the green success message confirming your files are indexed.
4. Ask questions in the chat box at the bottom of the screen.
5. Expand **📌 Source Citations** under any answer to see the exact file and page number it was drawn from.

Note: This app extracts text directly from PDFs. Scanned or image-only PDFs with no selectable text will not index correctly (OCR support is a planned enhancement).
